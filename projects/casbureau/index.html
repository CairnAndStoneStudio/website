CASBureau

Cairn and Stone Studio · Independent developer tooling · Sep 2026 – present

CASBureau is a local-first developer workspace I'm building for managing AI-assisted engineering across real software projects.

I designed and built the execution runtime behind it, with explicit task control, recorded validation and independent review. I'm now integrating these capabilities with projects, conversations and engineering work.

What I did

Execution runtime

I designed and built a repository-aware runtime that coordinates specialized agents through explicit task states and controlled transitions. Models perform assigned work, while the runtime governs execution and completion.

Validation and reliability

I implemented execution-backed validation, independent review and traceable evidence. Failures and interruptions are handled explicitly, with safeguards against retrying work whose side effects are uncertain.

Models and persistence

I built role-based model routing with isolated contexts and support for multiple providers. Append-only events and immutable records preserve execution history and validation evidence.

Product integration

I'm developing the CASBureau workspace to connect projects, conversations, tasks and engineering activity in one interface. This integration is still in progress.

Technical proof

  • Agentic development

    Specialized agents with isolated contexts, explicit orchestration and independent review, rather than model-controlled task progression.

  • Architecture

    Separation between the workspace, execution runtime, conversation harness and model providers, with explicit responsibilities and authority boundaries.

  • Reliability

    Execution-backed validation, recorded evidence and controlled recovery from interrupted or uncertain executions.

  • Local-first data

    Append-only events and immutable execution records supporting persistent state, traceability and recovery.

  • Developer tools

    Reusable execution runtime and CLI integrated with Git repositories, including automated validation and execution tracking.

  • AI infrastructure

    Role-specific model routing across providers, constrained by engineering requirements and reviewer independence.

  • Product engineering

    Ongoing integration of projects, conversations, tasks and execution history into a unified local-first developer workspace.
