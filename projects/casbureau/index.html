CASBureau

Cairn and Stone Studio · Sep 2026 – present · independent tooling, built outside client work

CASBureau is the runtime I built to make AI-assisted development answerable. Models interpret and propose, while the runtime owns task state, execution order and authority. It records what was actually executed and tested, and who reviewed it. Work moves through bounded execution, required validation and independent review in an ordinary Git repository, while intent and scope remain with the human.

What I did

I designed the workflow and built the runtime that enforces it. Execution is serialized against a working repository so agents operate on a stable source of truth, while independent repositories can run concurrently. Agent permissions are bounded, and an independent review must pass before work can close. Required checks execute as bounded commands rather than relying on an agent's declaration. Their results are recorded as evidence and used to generate the final report.

Technical proof

  • Agentic development

    Specialist roles run in sequence, with an independent review and recorded evidence rather than one agent asked to do everything.

  • Developer tools

    A project-neutral runtime and CLI, installable into a consumer repository, with a test suite that runs without consuming model quota.

  • Architecture

    Defined the sequential lifecycle and the authority boundaries between agents, model providers and the human; orchestration is explicit, not a model's decision.

  • Reliability

    Executed validation, secret redaction and safe recovery built into the lifecycle rather than left to convention.
