Sebastian2 post-production network

Mikros Image · Oct 2008 – Sep 2010 · professional network for post-production

Sebastian2 was a professional network for the post-production industry, built at Mikros Image. I worked across the stack, with identity and access management as a central part of the system.

←Today Tomorrow MMORPG All projects 12 of 12

What I did

I created the access-control model and evaluated Liberty Alliance and OpenID as protocol options. I then built the Java server with Hibernate, Restlet, EMF and Teneo, an OpenLDAP communication library, and the Flex interface. I installed and configured PostgreSQL, LDAP and MySQL, and deployed a virtualised compute grid under CentOS with NFS and firewall configuration.

Technical proof

  • Architecture

    Access control, Java backend, Flex UI, and the directory and database layers supporting the application.

  • Distributed systems

    A virtualised computing grid deployed under CentOS with NFS and firewall configuration.
