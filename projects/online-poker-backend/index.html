Online poker backend

Winamax · Sep 2011 – Nov 2012 · high-traffic online poker platform

Winamax runs online poker at a scale where the backend is the core of the product. I built platform modules in event-driven C++, in a codebase where concurrency, messaging and memory behaviour directly affect game execution, latency and reliability.

What I did

I developed new platform modules in C++ using libevent and OpenAMQ for event-driven messaging, and worked on multithreaded code and performance optimisation. I also used debugging, profiling and scripting to investigate and improve behaviour in a live, high-traffic production environment.

Technical proof

  • Scalability
